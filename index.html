Добавить списком артикулов

Вставьте артикулы из переписки: через перенос строки, запятую, «;», «/» или пробел, регистр не важен. Количество — до или после артикула: «IS-BAL-1100 x2», «2 шт IS-BAL-1100». Слова без цифр пропускаются, ненайденные артикулы остаются в поле.

      Быстро собрать КП и увидеть проверки в действии. Изменения мока PIM живут до перезагрузки страницы.

      Прототип к тестовому заданию. Товары — встроенный мок PIM за адаптером pimAdapter (поиск, карточка по артикулу); в v1 на его место встаёт API или выгрузка PIM. Запись в сделку — имитация, в v1 — REST API Битрикс24. Бренды, артикулы, цены и реквизиты выдуманы.
