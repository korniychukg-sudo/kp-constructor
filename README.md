# Конструктор КП · прототип

Прототип внутреннего инструмента для подготовки коммерческих предложений: подбор товаров из каталога, добавление списком артикулов, скидки с лимитом, расчёт сумм и НДС, проверки перед выпуском, предпросмотр КП и сохранение в PDF.

Один HTML-файл без библиотек и сетевых запросов. Каталог, клиент и реквизиты условные.

Открыть: https://korniychukg-sudo.github.io/kp-constructor/
